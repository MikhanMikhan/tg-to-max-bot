# Глоссарий

## Площадка
Соцсеть/мессенджер, где публикуется контент. В текущем скоупе — две: Telegram и MAX.

## Пост-источник
Пост, опубликованный автором в Telegram-канале. Точка входа в систему: всё начинается с того, что пост появился в Telegram.

## Источник (Telegram)
Telegram-канал автора. Система читает его через официальный Bot API: бот добавлен администратором канала и получает события «новый пост» и «пост отредактирован». Известное ограничение: Bot API не сообщает об удалении постов, поэтому пост, удалённый до времени публикации дубля, всё равно будет продублирован — принятая оговорка.

## Приёмник (MAX)
Канал в мессенджере MAX, куда публикуются Дубли. Публикация идёт через официальный MAX Bot API (метод POST /messages в канал). Доступ к API: у автора есть верифицированный статус (самозанятый/ИП/юрлицо РФ) на business.max.ru, токен бота получен.

## Дубль
Дословная копия Поста-источника, публикуемая в MAX. Без адаптации. Переносятся все типы контента, поддерживаемые MAX Bot API: текст, фото (включая альбомы), видео, аудио, файлы. Элементы, не переносимые в MAX (опросы, inline-кнопки, спойлеры и т.п.), молча отбрасываются — уведомления о потерях не присылаются, принятое решение. Скоуп сознательно урезан до одной пары «Telegram → MAX»; универсальная модель «Материал → Версии под площадки» отклонена как избыточная.

## Время дубля
Момент публикации Дубля в MAX. По умолчанию — Пост-источник + 1 час. При появлении Поста-источника бот пишет автору в личку: «выйдет в <время>»; автор может ответить другим временем и переопределить. Молчание = дефолт.

## Очередь дублей
Посты-источники с назначенным Временем дубля, ожидающие публикации. Дубль снимается как слепок актуального состояния поста на момент публикации: правки до публикации учитываются (бот получает события редактирования), правки/удаления после выхода дубля игнорируются. Очередь стойкая: при сбое публикации дубль остаётся в очереди, повторные попытки по нарастающему интервалу; пропущенное из-за простоя догоняется при старте; после исчерпания попыток автору приходит уведомление в личку Telegram.

## Связка
Пара «Telegram-канал → MAX-канал», подключённая владельцем в личке бота. Определяет, куда дублируются посты конкретного Источника, задержку дубля и часовой пояс. Посты из каналов без активной Связки игнорируются.

## Тенант
Связка глазами Системы: запись в БД (владелец, TG-канал, MAX-канал, задержка, активность). Один экземпляр Системы обслуживает много Тенантов. Отключённый Тенант (`/disconnect`) перестаёт публиковать дубли: ожидавшие публикации записи отменяются.

## Система
Скрипт/сервис на Python (aiogram для Telegram Bot API, официальный maxapi SDK для MAX, очередь в SQLite). Работает без публичного IP: long-polling для Telegram, исходящие запросы для MAX. Запускается локально на машине автора с возможностью переноса на VPS без изменений кода.
